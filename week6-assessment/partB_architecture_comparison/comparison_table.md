## ANN vs CNN vs RNN – Comparison

| Aspect | ANN | CNN | RNN |
|------|-----|-----|-----|
| Full Form | Artificial Neural Network | Convolutional Neural Network | Recurrent Neural Network |
| Type of Data Used | Structured or numerical data | Image and spatial data | Sequential or time-dependent data |
| Main Idea | Connects all neurons layer by layer | Uses filters to extract image features | Remembers previous inputs |
| Spatial Feature Handling | Does not consider spatial relation | Preserves spatial structure | Not designed for spatial data |
| Memory of Past Inputs | No memory | No memory | Has memory through hidden states |
| Common Layers | Dense (Fully Connected) layers | Convolution and pooling layers | Recurrent layers |
| Parameter Sharing | No | Yes (same filters used) | Yes (across time steps) |
| Computational Cost | Low | Medium | High |
| Typical Applications | Basic classification, regression | Image classification, object detection | Text processing, speech recognition |
| Example Use Case | Predicting marks from features | Handwritten digit recognition | Sentiment analysis of text |
