# Week 6 Assessment – Deep Learning and Generative AI

This repository contains the Week 6 assessment work completed as part of the CreativeArc Internship program. The assessment focuses on neural network fundamentals, architecture comparison, training stability, and an introduction to Generative AI and Large Language Models.

## Folder Structure

- **partA_neural_basics**  
  Implementation of a Multi-Layer Perceptron (MLP) on the Fashion-MNIST dataset. Includes training and validation loss analysis.

- **partB_architecture_comparison**  
  Comparison of ANN, CNN, and RNN architectures using simple PyTorch implementations and a comparison table.

- **partC_training_stability**  
  Experiments demonstrating the effect of learning rate, batch normalization, and dropout on training stability.

- **partD_genai_llm**  
  Basic demonstration of text generation, prompt testing, and discussion of hallucination issues in Large Language Models.

## Technologies Used
- Python  
- PyTorch  
- VS Code  

## Outcome
Through this assessment, practical understanding of deep learning models, training behavior, and Generative AI concepts was developed.
