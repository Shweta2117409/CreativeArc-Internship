# Week 5 Assessment – Optimization & ML Engineering

This assessment focuses on building a complete and reproducible machine learning
pipeline, covering optimization, evaluation, and deployment readiness.

## Contents
- Data understanding and baseline modeling
- Feature engineering and ablation study
- Hyperparameter tuning
- Cross-validation and nested cross-validation
- Model persistence and reproducibility
- Final model selection and reflection

## Dataset
The Heart Disease dataset is used for all experiments. Appropriate preprocessing,
feature engineering, and validation strategies are applied.

## Outcome
A fully reproducible ML pipeline was developed, evaluated, and saved for reuse.
The workflow follows standard ML engineering best practices.
